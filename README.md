# gas-copy-event

Google Apps Script で、複数の同期元 Google カレンダーの予定を同期先カレンダーへコピーするスクリプトです。

同期先カレンダーの予定を毎回すべて削除して作り直すのではなく、スプレッドシートに同期状態を保存し、差分だけを作成・更新・削除します。

## できること

- 複数の同期元カレンダーから予定を取得する
- 同期先カレンダーへ `[別名] 予定名` の形式でコピーする
- 説明と場所をコピーする
- 終日予定と時間指定予定の両方に対応する
- スプレッドシートを仮置き場として使い、同期済みイベントを追跡する
- 仮置きシートを年月単位で分ける
- 同期対象外になった古い年月シートを自動削除する
- 緊急時に同期済み予定と仮置きシートをまとめてリセットする

## 設定

[main.gs](./main.gs) の先頭にある値を設定します。

```js
const FROM_CALENDAR_CONFIG = [
  { id: '同期元カレンダーID', name: '表示名' },
];

const TO_CALENDAR_ID = '同期先カレンダーID';
const STAGING_SPREADSHEET_ID = '';
```

`FROM_CALENDAR_CONFIG` には同期元カレンダーを複数指定できます。

```js
const FROM_CALENDAR_CONFIG = [
  { id: 'source-calendar-1@example.com', name: '仕事' },
  { id: 'source-calendar-2@example.com', name: '個人' },
];
```

`STAGING_SPREADSHEET_ID` は同期状態を保存するスプレッドシートIDです。

- スプレッドシートに紐づく Apps Script として使う場合は空文字のままでOKです
- スタンドアロン Apps Script として使う場合はスプレッドシートIDを設定してください

## 実行する関数

### 通常同期

```js
initSync()
```

同期元カレンダーから予定を取得し、同期先カレンダーへ差分同期します。

同期対象期間は `getSyncRanges()` で定義しています。

```js
return [
  [0, 2],   // 今日・明日
  [2, 14],  // 2日後〜2週間後
  [15, 60]  // 15日後〜60日後
];
```

必要に応じて Apps Script のトリガーから `initSync` を定期実行してください。

### 緊急リセット

```js
emergencyResetAllSyncedEvents()
```

バグった時などに手動で全リセットするための関数です。

この関数は次の処理を行います。

- 仮置きシートに記録されている同期先イベントを削除する
- 同期対象期間内に残っている `[別名] ` 始まりのコピー予定も削除する
- `calendar_sync_` で始まる仮置きシートを削除する

手動で作った予定まで消さないよう、カレンダー実体から削除する対象は `[別名] ` で始まるコピー予定に限定しています。

## 仮置きシート

同期状態は `calendar_sync_YYYY-MM` という名前のシートに保存されます。

例:

- `calendar_sync_2026-06`
- `calendar_sync_2026-07`

`initSync()` 実行時、現在の同期対象期間に含まれない古い `calendar_sync_YYYY-MM` シートは自動削除されます。

## 注意点

- 同期先カレンダー上でコピー予定を手動編集しても、次回同期時に同期元の内容で上書きされます
- 同期元から予定が消えた場合、対応する同期先予定も削除されます
- 初回実行時、仮置きシートが空の場合は `[別名] ` で始まる既存コピー予定を掃除してから同期します
- 緊急リセットは削除処理なので、実行前に対象カレンダーと設定値を確認してください
